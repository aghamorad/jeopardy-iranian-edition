# Historical tools

This directory preserves superseded one-off generators and direct archive
writers. Do not execute them, adapt them, or use them as templates for MAIN-bank
work. They predate the append-only workflow and can overwrite the materialized
archive without its current validation and parts ledger.

For a new MAIN batch, leave this directory and use `Tools/append_batch.py`.
For forensic work, read a historical script without writing any project file.
