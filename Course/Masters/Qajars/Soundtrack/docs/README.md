# Qajar Jeopardy: Polished Music Pass

Second-pass procedural music and sound pack for the Qajar course of *Jeopardy: Iranian Edition*.

This pass is more polished than the first draft: stronger shared motif, cleaner mix, 24-bit WAV masters, smoother loop handling, folder organization, and cue-specific historical textures.

## Folder map

- `01_music_beds/`: longer loops and screen music
- `02_stingers/`: reveals, transitions, and syllabus-week stingers
- `03_sfx/`: very short gameplay UI sounds
- `docs/manifest.json`: metadata, usage, durations, loop flags
