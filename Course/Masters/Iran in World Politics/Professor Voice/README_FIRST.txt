IRAN IN WORLD POLITICS — PROFESSOR VOICE PACK (MALE)
====================================================

This is the corrected male version: 27 separate clips generated with the same deep male voice.

HOW TO GET THE WAV FILES
1. Double-click Build_MALE_Voice_Pack.command.
2. macOS downloads the 27 generated male recordings.
3. Each is converted to 48 kHz / 16-bit PCM WAV.
4. The finished folder AND finished ZIP are placed on your Desktop.

Output folder:
  ~/Desktop/Iran_World_Politics_Professor_MALE_Voice_Pack/

Output ZIP:
  ~/Desktop/Iran_World_Politics_Professor_MALE_Voice_Pack.zip

If macOS blocks the command: right-click it > Open > Open.

All lines are under 30 seconds, so the generated preview audio used by the builder contains the complete spoken line, not a truncated excerpt.
